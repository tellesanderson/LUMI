## Deploy

Hospedado via **GitHub Pages** no branch `main`.

Após criar o repositório `LUMI` no GitHub:
```bash
git init
git add .
git commit -m "Lançamento do site LUMI Decorações"
git branch -M main
git remote add origin https://github.com/tellesanderson/LUMI.git
git push -u origin main
```

Então ative GitHub Pages em: Settings → Pages → Branch: main / Root
