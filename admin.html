📢 Como Publicar no Site?

Como este site é estático, as alterações que você faz aqui ficam salvas de forma rascunho apenas no seu computador. Para colocar as alterações no ar para os clientes, use as opções abaixo:

1. Atualizar Código do Site

Copie o código abaixo e cole dentro do arquivo js/themes.js do seu site no servidor/hospedagem para atualizar permanentemente.

2. Backup de Segurança (JSON)

Salve um arquivo de segurança com todas as suas edições no seu computador.

3. Restaurar Padrões

Apaga todas as edições locais e recarrega os 15 temas originais da LUMI Decorações.
